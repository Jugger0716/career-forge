# 실재하지 않는 경로를 참조하는 SKILL.md

negative 픽스처(케이스 28). 이 문서는 `scripts/does-not-exist.mjs`를 파이프라인의
한 단계로 안내하지만 그 파일은 레포에 없다.

**이 검사가 왜 필요한가.** 프롬프트는 마크다운이라 링크가 깨져도 아무것도
빨개지지 않는다 — 스킬이 실행되는 시점에야 "그런 파일이 없다"가 드러나고,
그때는 이미 사용자가 명령을 부른 뒤다. 특히 이 플러그인은 산문이 아니라
**호출할 명령**을 프롬프트에 적으므로, 경로 오타가 곧 실행 실패다.
